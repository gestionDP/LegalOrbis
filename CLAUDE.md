## Qué es este repositorio

`LegalOrbis` es la **web de LegalOrbis**, un bufete legal. Clasificación dentro del grupo GDP pendiente (¿marca propia, socio, o cliente?).

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind 4 · shadcn/ui · Framer Motion · Embla Carousel

## Comandos

```bash
npm install
npm run dev        # Dev server
npm run build      # Build producción
npm run lint       # ESLint
npm run generate-favicons  # Generar favicons (tsx script)
```

## Estructura

- `app/` — App Router (páginas)
- `components/` — Componentes React
- `hooks/` — Custom hooks
- `lib/` — Utilidades
- `scripts/` — Scripts (favicon generation)
- `types/` — TypeScript types
